# 圆环场景的缩放、透视与轨迹修复

原来的背景采用 `object-fit: cover`，玻璃和兔子却分别使用视口百分比、固定 rem/px 尺寸及独立的移动端坐标。窗口比例、文字排版或页面缩放变化后，背景与覆盖层的坐标不再一致；玻璃还被分别拉伸宽、高，失去素材原有透视。

修复将背景、圆环内轮廓、三片玻璃、兔子及折射切片统一到原图的 1536 × 1024 坐标系。整个画布等比例缩放和裁切，移动端只改变整幅画布的位置。宽屏场景高度随画布增长，避免缩小时截断装置。

`src/lib/research-scene.ts` 集中维护原图坐标。玻璃按素材 alpha 边界定位并保持原始宽高比例，三片的完整边界均位于圆环内。圆环遮挡使用从实际内沿取样的平滑 SVG 裁剪路径，保留原图的倾斜透视。

兔子沿原图 y=495 的水平线移动，从左侧圆环后进入，依次穿过三片玻璃，再由右侧圆环遮挡。每个空间区间只显示对应形态，玻璃入口和出口各使用一个折射形态，消除重复叠影。折射偏移、点云层间偏移和局部纹理均随主体同比例缩放。

验证：

- 生产构建检查 0 errors / 0 warnings，86 项单元测试及 57 项源码、产物测试通过。
- 在 320、390、720、768、960、1152、1440 像素宽度下核对玻璃的原图坐标、宽高比例及页面溢出。
- 用 CSS 视口与 DPR 联动模拟 80%、100%、125%、150%、200% 页面缩放；同一个页面连续切换后，玻璃坐标和兔子相对尺寸保持一致。该检查不是操作浏览器原生缩放菜单。
- 正向与反向检查六个滚动位置，轨迹一致。120 帧往返滚动新增布局次数为 0；减少动态效果仍切换至静态构图。
- 玻璃宽高比例误差从原平板场景约 77% 降至小于 0.1%，剩余差异为 CSS 子像素取整。
- 图片元素从 30 个减至 22 个；提高了玻璃响应式图片的采样尺寸以保留透视边缘，场景仍通过原有 300 KiB AVIF 与遮罩预算。
